Inpaint integration

Inpaint app

In Inpaint, click API server in the folder browser, enable the server and copy its access token.

Immich

Pictures on this Immich server are read through its API, as the account signed in on the Immich page. Saving writes an edit back to the library file when its folder is mapped below, then asks Immich to regenerate the thumbnail.

Only used when a request cannot go through the Immich page. Create it in Immich under Account Settings → API Keys with the permissions asset.read, asset.view, asset.download and job.create.

Library folders

Map the start of an asset's path as Immich shows it to the same folder mounted on this computer. Add the local folders to Inpaint's allowed folders as well. Edits of assets outside mapped folders go to Inpaint's save folder.

Using it

Press Alt+Shift+I on a page, or right-click and choose Inpaint panel, then pick a picture: similar pictures on that site get a small Inpaint button. Hover it for the actions. Results replace the picture on the page until you save.

Right-click any picture and choose Open in Inpaint to edit it in the app.
